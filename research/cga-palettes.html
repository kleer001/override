Sixteen-colour
intrusion

Three ways to repaint the EXEC screen for a 1983 CGA monitor. Every colour is drawn from the 16-colour IBM CGA hardware palette — nothing invented — and mapped onto the real Tier-1 intrusion board. Monochrome amber was the MVP; on this game the burn is the payload, so colour is a gameplay signal, not polish.

The constraint — IBM CGA, 16 colours

Bench
Read-out. Open ground stays black on every specimen — CGA screens are black-ground, and an unburned cell should read as empty machine. The glyph vocabulary never changes (▓ wall, ▒ hard, @ # the spreading intrusion, ╬ ║ the targeting gnomon, ─ the trace scan, $ vault, " honeypot), so this is a pure paint pass: a per-cell colour lookup keyed on the character the renderer already emits. No gameplay, hit-testing, or layout is touched. Pick one and it drops into styles.css + a small class in src/juice.js.
